¿Cómo envía eventos un agente?

Cada activo envía lotes de eventos por HTTPS a la API REST, autenticándose con su API key:

POST /api/v1/ingesta/eventos
X-API-Key: sp_xxxxxxxx_…
Content-Type: application/json

{ "eventos": [ { "categoria": "AUTH_FALLIDA", "ip_origen": "181.43.2.10", "usuario_objetivo": "admin" } ] }
